# dimensionamiento-bess

App de dimensionamiento de sistemas BESS (Battery Energy Storage Systems) para sistemas fotovoltaicos existentes bajo CRE A/113/2024.

**Alcance Wave 1:** SFV existente + BESS, sin modificación de capacidad CFE.

## Stack

Vite + React 19 + TypeScript strict + Tailwind + shadcn/ui + Recharts + Vitest.

## Desarrollo

```bash
npm install
npm run dev
```
